Every check, in plain English

Each finding comes with why it matters and how to fix it. Critical issues cost 15 points, warnings 6.

Consent & privacy
  • criticalConsent Mode not implemented
  • criticalConsent Mode v1 only (ad_user_data / ad_personalization missing)
  • criticalConsent default set too late, or update sent without default
  • criticalAccepting cookies doesn't update Google consent
  • criticalPixels fire, or Google consent is granted, after "reject all"
  • criticalMeta / TikTok / LinkedIn / Pinterest / Snap / X / Reddit / Microsoft Ads firing while ad consent is denied
  • criticalTracking cookies present while consent is denied
  • warningad_storage defaults to granted with a CMP present
  • warningSession recorders (Clarity, Hotjar) load without analytics consent
  • criticalEmail addresses or unhashed advanced matching sent to any vendor
Data accuracy
  • criticalDuplicate page views (GA4, Meta, TikTok, Snap, Reddit, X, Microsoft Ads, Pinterest)
  • criticaldataLayer overwritten after GTM loaded
  • warningecommerce object not cleared between pushes
  • warningTag library loads but never sends a hit
  • warningTags still silent after full consent
  • warningPurchase value differs between GA4, Meta and TikTok
  • Multiple GTM containers or GA4 properties · server-side GTM detected
GA4 ecommerce & naming
  • criticalpurchase without transaction_id, value, currency or items
  • criticalSame purchase sent more than once
  • criticalvalue is not a number
  • warningItems missing item_id and item_name · price not numeric
  • warningCurrency not ISO 4217
  • warningEvent names over 40 chars, invalid characters, or reserved
  • warningMore than 25 parameters · parameter names over 40 chars
Meta Pixel
  • criticalPurchase missing value or currency
  • warningStandard event with the wrong case ("purchase" vs "Purchase")
  • warningEvent activated multiple times on one page
  • warningCatalog events without content_ids
  • warningValue not numeric · currency not ISO 4217
  • Conversions without event_id (CAPI dedup) · double-encoded parameters
TikTok Pixel
  • criticalPurchase events missing value or currency
  • warningProduct events without content_id
  • warningcontent_type not "product" / "product_group"
  • warningMalformed advanced-matching email · phone not E.164
  • Purchase without event_id (Events API dedup)

FAQ

Does it see server-side tracking like Meta CAPI or GA4 Measurement Protocol?

No browser extension can: those events go from the client's server, not the browser. We detect first-party server-side GTM endpoints, flag missing event_id for CAPI deduplication, and say clearly in the report that server-side events are out of scope.

How is this different from Tag Assistant or Meta Pixel Helper?

Those show you one vendor's tags. Tracking QA checks all vendors together against rules, including cross-vendor problems (pixels ignoring consent, purchase values that disagree), and produces a report you can send.

Will the consent test click buttons on my client's live site?

Only when you turn it on. It clicks the CMP's own "accept all" or "reject all", exactly like a visitor would, in your browser. Nothing is changed on the site.

What does "Fresh visitor" do?

Before scanning it clears cookies and storage for the scanned site only, so you see what a first-time EEA visitor sees. It logs you out of that site, so it's off by default and asks for permission first.

Why does it need access to all websites?

To see tracking requests on whatever site you audit. Only requests to known tracking endpoints are read; everything else is ignored. See the privacy policy.

Install

Chrome Web Store listing coming soon. Until then, install from source in under a minute:

  1. Download the latest ZIP and unzip it.
  2. Open chrome://extensions and switch on Developer mode.
  3. Click Load unpacked and choose the unzipped folder.
  4. Pin Tracking QA and click its icon to open the side panel.
